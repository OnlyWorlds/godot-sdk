# OnlyWorlds SDK for Godot

This folder is the addon: GDScript classes that read and write OnlyWorlds worlds, over the onlyworlds.com API and
on disk as world folders and `.owworld` files, with a class for each of the 22 element types. It runs on the
standard Godot build; no .NET is needed. Its version is in `plugin.cfg`.

Open your project in the editor once so Godot registers the `OW…` classes. Enabling the plugin under
**Project Settings → Plugins** is optional.

- The install, a first run and the guide: https://github.com/OnlyWorlds/godot-sdk#readme
- Every call: https://github.com/OnlyWorlds/godot-sdk/blob/main/docs/reference.md
- Issues: https://github.com/OnlyWorlds/godot-sdk/issues
